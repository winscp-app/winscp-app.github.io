How to use WinSCP: connect to an SFTP server and upload files

To learn how to use WinSCP you need three things from your host: a host name, a user name, and a password or key. This guide goes from the Login dialog to your first upload, using the dialog and button names the program shows.

To use WinSCP, open it, select New Site in the Login dialog, choose SFTP as the file protocol, and enter the host name, user name and password. Then click Login. The first time you connect, check the server's host key fingerprint and accept it. To upload, drag files from the local panel to the remote panel, or select them and press F5.

What you need before you start

Most questions about how to use WinSCP come down to missing connection details, so collect them first. The vendor's FAQ makes clear that the user name and password come from whoever runs the server, and that the developers cannot reset them for you. If the program is not installed yet, get it from the download page.

  • Host name or IP address of the server
  • Protocol and port: SFTP on port 22 is the most common, FTP uses port 21
  • User name
  • Password, or a private key file if the server uses key login
  • The server's host key fingerprint, from your administrator or hosting provider

Connect step by step

  1. Open the Login dialogStart the program. The Login dialog opens on its own. If you are already connected, open it again with the New Session command.
  2. Select New SiteIn the tree on the left, select New Site. The fields on the right are now empty and ready for a new connection.
  3. Choose the file protocolIn File protocol, choose SFTP for an SSH server, or SCP, FTP, WebDAV or Amazon S3. For FTP with TLS, also set Encryption. Port number fills in automatically: 22 for SFTP and SCP, 21 for FTP.
  4. Enter host and credentialsType the Host name, User name and Password. For key login, leave Password empty, click Advanced, open SSH > Authentication and select your private key file.
  5. Save the siteClick Save and give the site a name so you do not have to type the details again. You can choose to save the password; stored sites can be protected with a master password.
  6. Log in and check the host keyClick Login. On the first connection the program warns that the server is unknown and shows its host key fingerprint. Compare it with the one your administrator gave you, then accept it so the key is stored for next time.

Upload and download files

In the Commander interface your computer is in the left panel and the server is in the right panel. Select files on the left and press F5, or drag them across. An upload dialog shows the target folder and transfer settings. Click OK to start. To download, do the same from the right panel to the left.

In the Explorer interface you drag files from File Explorer or the desktop into the remote window, and drag files out of it to download them. Either way, large jobs can go to the transfer queue and run in the background. An interrupted transfer resumes instead of starting again. The program picks binary or text mode for you, and you can change it in the transfer settings.

Edit and synchronize

To change a file on the server, select it and press F4 (Edit). It opens in the integrated editor, and saving uploads the new version. You can choose an external editor in the preferences if you prefer your own.

To mirror a folder, use Commands > Synchronize. You can choose the direction: local, remote or both. To upload changes as you save them while you work, use Commands > Keep Remote Directory up to Date. The vendor's FAQ explains each direction option.

Next step: automate it

Once a site works in the graphical client, you can turn it into a script. In the Login dialog, Manage > Generate Session URL/Code writes the connection as a session URL, a script line or .NET code that you can paste into a batch file or PowerShell. The scripting tools and the .NET assembly are part of the same free licence, as the licence page explains.

If the connection fails at any point, the error fixes page covers login failures, host key warnings and script problems. For an overall view of what else the program can do, read the review.

FAQ

Which port does WinSCP use for SFTP?

Port 22 by default, the standard SSH port. Some hosts run SSH on a different port; if so, enter the number your host gives you in the Port number field.

How do I save the password for a site?

Click Save in the Login dialog and tick the option to save the password. Set a master password in the preferences if other people use the same Windows account.

Where do I get the host key fingerprint?

Ask the server administrator or look in your hosting provider's control panel or documentation. Compare it with the fingerprint the program shows before you accept it.

Can I connect to an FTP server?

Yes. Choose FTP in File protocol. If the server supports TLS, also set Encryption, so the password and files are not sent in plain text.

Why does it keep asking for my password?

Either the password was not saved with the site, or the prompt is for the passphrase of your private key. Load the key into Pageant, or into the OpenSSH agent since version 6.7, so you type the passphrase only once per Windows session.

Can I transfer files directly between two servers?

Not directly; files pass through your PC. Download from the first server and upload to the second, or run a copy command on one of the servers if you have shell access.

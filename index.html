WinSCP is a free, open source file transfer client for Windows. It copies files between your PC and remote servers over SFTP, SCP, FTP, FTPS, WebDAV and Amazon S3. The current stable release is 6.7.1, a 13 MB installer from the official site. There is no paid edition, and a Microsoft Store copy at $19.99 is optional.

What WinSCP is for

WinSCP is a free Windows program built for one job: copying files between your computer and a remote machine. You open a session to a server, see your local folders and the remote folders side by side or in a window that looks like File Explorer, and move files by dragging them or with a keyboard shortcut. The official introduction calls it an SFTP, FTP, WebDAV, S3 and SCP client, with basic file manager functions on top.

People turn to it when a web host sends them SFTP or FTP details, when they look after a Linux server from a Windows desk, or when they need to upload to an Amazon S3 bucket without typing commands. It also edits remote files in place with its own text editor, keeps folders in sync, and can run unattended from scripts or from a .NET assembly.

It runs only on Windows. Development has continued without a break since 2000, and a new release comes out every one to three months.

Main features in version 6.7

The feature list in the official documentation is long. These are the parts most readers use day to day.

  • Two interfaces: Commander, with two panels and keyboard control, and Explorer, with a single remote window
  • SFTP and SCP over SSH, FTP with optional TLS encryption (FTPS), WebDAV and Amazon S3
  • Password, keyboard interactive, public key and Kerberos (GSS) authentication, with support for Pageant
  • Integrated text editor for remote files
  • Folder synchronization, a background transfer queue and resuming of interrupted transfers
  • Scripting, a command line interface and a .NET assembly for automation
  • Optional master password for stored sites, and a portable mode that keeps settings in a file instead of the registry

Version 6.7 adds synchronization between two local folders, support for the OpenSSH authentication agent, better handling of sessions and workspaces, improved dark theme support and an experimental 64 bit build.

Who should use it and who should not

It suits Windows users who move files to servers they own or rent: web developers, system administrators, and anyone who has been given SFTP credentials by a hosting provider. Scripting and the .NET library come in the same free download, so it also suits teams that automate nightly uploads or reports.

It does not suit people who need one client on Windows, macOS and Linux, or who want direct connections to consumer cloud drives such as Google Drive or Dropbox. Those readers should compare other clients before they install anything.

FAQ

What is WinSCP used for?

It copies files between a Windows PC and a remote server over SFTP, SCP, FTP, WebDAV or S3. It can also edit remote files, keep folders in sync and run automated transfers from scripts.

Is WinSCP safe to download?

The installer on the official site is the vendor's own build of an open source program. Get it from winscp.net rather than a mirror, and click the main download button rather than the advertisements shown on that page.

Does it work on Mac or Linux?

No, the program is for Windows only. Mac and Linux users need another client, such as FileZilla or Cyberduck.

Is there a paid version?

No. Every feature is in the free download. The Microsoft Store listing costs $19.99 and is another way to get the same program, not an upgrade.

What is the latest version?

The current stable release is 6.7.1, checked on 24 November 2026. The vendor ships updates every one to three months.
